/annotate

Add a comment layer to any HTML prototype for engineering handover. Place numbered pins with categorised notes directly on screens — comments save into the HTML file itself.

Note Logic Reference

Install

Download the zip below, unzip it, and drop the annotate folder into your project's .claude/skills/ directory. The folder structure must look exactly like this:

your-project/
  .claude/
    skills/
      annotate/
        skill.md required
        annotate-module.html
Heads up: The .claude folder is hidden by default in Finder. Press Cmd + Shift + . to toggle hidden files, or create it from the terminal.
  1. 1

    Download the skill

    Grab the zip from the link below (or clone the GitHub repo). Unzip it — you'll get an annotate/ folder with two files inside.

  2. 2

    Add it to your project

    Move the annotate/ folder into .claude/skills/ in whichever project you're prototyping in. Create the folders if they don't exist:

    # from your project root mkdir -p .claude/skills # then move the unzipped folder in mv ~/Downloads/annotate .claude/skills/
  3. 3

    Restart Claude Code

    Close and reopen your Claude Code session (or start a new one in the project). The skill registers on startup.

  4. 4

    Run it

    Type /annotate in your Claude Code session. Claude will find your HTML prototype, inject the comment layer, and open a preview.

How it works

Toggle Click the pin button (bottom-right) to show/hide comments
Add Click Add comment in the toolbar, then click anywhere on the screen
Save Cmd/Ctrl+Enter saves a note. Tell Claude "save comments" to persist to the file.
Browse Click All comments to open the drawer — click any comment to jump to its screen
Delete Delete a comment from its popover. A 30-second undo toast appears in case of accidents.
